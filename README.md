# Прикладная разработка

Разрабатываю веб-приложения и консольные инструменты. В проектах уделяю внимание структуре кода, воспроизводимому запуску, тестам и понятной документации.

## Проекты

| Проект | Что внутри |
| --- | --- |
| [LegalAI](https://github.com/cushog74/legalai-showcase) | Система ведения дел и анализа документов: FastAPI, SQLAlchemy, React, TypeScript, поиск по тексту, ролевой доступ, синтетические демонстрационные данные. |
| [Config Diff CLI](https://github.com/cushog74/config-diff-cli) | Утилита на Node.js для сравнения JSON и YAML с тремя форматами вывода и автоматическими тестами. |

## Технологии

Python · JavaScript · TypeScript · FastAPI · React · SQLAlchemy · SQLite · Node.js · pytest · GitHub Actions
